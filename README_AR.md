# مكتبة القيّوم — حزمة الواجهة الموسّعة ومخططات المنصة

هذه الحزمة توسعة للواجهة المرجعية التي اعتمدها مالك المشروع. الصفحة الرئيسية تحافظ على الهوية البصرية في صورة المرجع: الكحلي الملكي، الذهبي، العاجي، زخارف إسلامية، بطاقات الأقسام، لوحات أحدث الإضافات والأقسام المميزة، والعبارة الوسطية. أُضيفت واجهات داخلية متجاوبة للوحدات التي جرى الاتفاق عليها.

## التشغيل والمعاينة
1. فك ضغط الحزمة.
2. افتح `index.html` محلياً أو ارفع محتويات المجلد إلى جذر مستودع GitHub Pages.
3. لا يحتاج نموذج الواجهة إلى بناء (build step).
4. بعض الخطوط تُحمّل من Google Fonts، مع خطوط احتياطية عند عدم توفر الاتصال.

## الواجهات المضافة
- الصفحة الرئيسية المطابقة للهوية المرجعية.
- فهرس المكتبة والبحث المتقدم وفلاتر المذهب/المدرسة والتخصص واللغة، مع 18 تصنيفاً رئيسياً وفق ملف التصنيفات الموجود.
- مركز البحوث والمشاريع العلمية وحفظ مسودات محلية.
- موسوعة الروايات والبحث في المتون والرواة والأسانيد.
- التقويم الهجري الافتراضي مع التاريخ الميلادي وملاحظة اختلاف ثبوت الأشهر والمناسبات.
- الوضع العلمي: دفتر المطالعة والتحقيق والاقتباسات والملاحظات.
- المجموعات والقنوات وسلم المستويات العشرة والأوسمة وقواعد احتساب النقاط. لا توجد رسائل خاصة بين الأعضاء؛ التفاعل العام يكون داخل المجموعات والقنوات.
- مركز الإشعارات وتفضيلات القنوات.
- تصميم مركز تحكم المالك وتقارير الإدارة.
- بوابة دخول توضيحية، إعدادات اللغة والخصوصية وإمكانية الوصول، ونموذج الدعم.

## تنبيه وظيفي وأمني مهم
هذه نسخة واجهة أمامية قابلة للمعاينة. الهدف المستقبلي هو فهرسة 100,000 كتاب شيعي و100,000 كتاب سني، مع بقية المدارس بأعداد مفتوحة؛ هذه أهداف وليست أعداداً موجودة حالياً. لا تدّعي الواجهة وجود فهرس كتب حي، أو تسجيل دخول حقيقي، أو صلاحيات خادم، أو إرسال إشعارات، أو نسخ احتياطي فعلي. المسودات والملاحظات التجريبية تُحفظ محلياً في المتصفح فقط. لا تدخل كلمات مرور حقيقية في نموذج الدخول التجريبي.

## قاعدة البيانات
ترتيب ملفات SQL:
1. `database/001_core_schema.sql`
2. `database/002_platform_modules.sql`
3. `database/003_catalog_import.sql`
4. `database/004_security_community_backups.sql`

ملف `004` يضيف تفضيلات اللغات والتقويم والإشعارات، نقاط ومستويات المجموعات، مستويات الموظفين، البلاغات والاستئناف، أحداث الأمان والجلسات ووسائل MFA، وسياسات وسجلات النسخ الاحتياطي. هذه مخططات قاعدة بيانات فقط وتحتاج API وخدمات خارجية.

## البنية المطلوبة قبل الإطلاق العام
- PostgreSQL 16+ مع تشغيل ملفات SQL بالترتيب أعلاه.
- API خلفي للتحقق من الصلاحيات والتحقق من صحة المدخلات.
- مزود مصادقة آمن مع MFA، تخزين تجزئات كلمات المرور، وإدارة الجلسات.
- تخزين كائنات خاص ومشفّر للكتب والملفات والنسخ الاحتياطية.
- محرك بحث وفهرسة نصية يدعم العربية واللغات الأخرى.
- خدمة إشعارات Push للمتصفح والهاتف.
- جدولة نسخ احتياطية يومية وأسبوعية وشهرية مع اختبار الاستعادة.
- إعداد CORS وHTTPS ومحددات المعدل ومراقبة السجلات.

## حماية حساب المالك
- لا تضع كلمة المرور أو مفاتيح API أو أسرار MFA داخل HTML أو JavaScript أو مستودع GitHub.
- إنشاء حساب المالك 313 يتم من خلال إجراء آمن على الخادم بعد نشر البنية الخلفية.
- التحقق بخطوتين إلزامي للمالك، واختياري لبقية المستخدمين.
- المديرون يعملون ضمن صلاحيات يمنحها المالك ولا يستطيعون رفعها ذاتياً.

## حقوق النشر والفهرسة
لا يُستضاف أو يُتاح تنزيل ملف إلا بعد التحقق من الترخيص أو الإذن. تحفظ بيانات المصدر ومعرّف السجل الخارجي والطبعة وحقوق الإتاحة. لا تُعد بيانات الفهرسة دليلاً على حق إعادة نشر النص أو الصورة.

## هيكل المشروع
- `index.html` الواجهة الأساسية.
- `styles.css` الهوية والتجاوب.
- `app.js` التنقل والتفاعلات المحلية التجريبية.
- `assets/` الصور المرجعية والعناصر البصرية.
- `database/` مخططات PostgreSQL.
- `docs/` مخطط البيانات وقوالب الاستيراد ودليل المصادر.

## تحديث الواجهة وفق المرجع البصري الجديد
- أُزيل تخطيط الصفحة الرئيسية السابق واستُبدل بتخطيط يحاكي الصورة المرجعية الجديدة: شريط علوي كحلي، هوية مكتبة القيّوم، شريط بحث وفلاتر، إحصائيات، قائمة أقسام جانبية، بطاقات كتب، ولوحات الأخبار والبحوث والمقالات.
- تم توحيد الاسم الظاهر في الواجهة إلى «مكتبة القيّوم» وعدم إبقاء اسم «الموسوعة الإسلامية الكبرى» في الواجهة.
- بطاقات الكتب الستة نماذج تصميمية فقط، وليست ادعاءً بوجود ملفات كتب أو فهرس حي. الإحصائيات تعرض حالة غير مفعّلة بدلاً من أرقام مختلقة.
- حُفظت الصورة المرجعية المرسلة باسم `assets/qayyum-home-reference-2026.png`.
- بقيت صفحات الوحدات الداخلية ومخططات قاعدة البيانات ضمن المشروع، بينما أُعيد تنظيم الصفحة الرئيسية فقط وفق التصميم المعتمد.
