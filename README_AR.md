# مكتبة القيّوم — حزمة الواجهة والخطة

## رفع الواجهة
1. فك ضغط الحزمة.
2. افتح مجلد `Al-Qayyum-Islamic-Library`.
3. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages، بحيث يكون `index.html` في الجذر.
4. فعّل GitHub Pages من الفرع والمجلد الصحيحين.

## الملفات المهمة
- `index.html`, `styles.css`, `app.js`: الواجهة الحالية.
- `assets/`: صور الهوية والواجهة المرجعية والأقسام.
- `locales/languages.json`: العربية الأصلية و50 لغة إضافية مع اتجاه الكتابة.
- `database/001_core_schema.sql` إلى `004_security_community_backups.sql`: مخططات قاعدة البيانات.
- `docs/MASTER_PLAN_AR.md`: الخطة الشاملة والقرارات.
- `docs/ROADMAP_AR.md`: مراحل التنفيذ.

## تنبيه تقني
هذه واجهة Front-end وليست منصة مكتملة الخدمات. اختيار لغة غير العربية يبدّل اسم اللغة واتجاه الصفحة فقط؛ ملفات الترجمة الكاملة غير منجزة. النماذج التجريبية لا ترسل بيانات إلى خادم. يجب مراجعة ملفات SQL وتشغيلها على PostgreSQL تجريبي قبل أي نشر إنتاجي.

## الاختبارات التي أُجريت على الحزمة
فحص صياغة JavaScript باستخدام Node.js، وفحص JSON، وفحص وجود ملفات الواجهة والصور وملفات SQL الأربعة، وفحص سلامة ZIP. لم يُجر اختبار PostgreSQL حقيقي لعدم توفر خادم PostgreSQL في بيئة التجهيز.
