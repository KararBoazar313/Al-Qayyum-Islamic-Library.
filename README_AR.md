# مكتبة القيّوم — الواجهة الموحدة والحزمة الأساسية

## قرار الواجهة المعتمد
هذه النسخة تعتمد تصميماً واحداً فقط: صورة الواجهة المرجعية التي زوّد بها صاحب المشروع، مع استبدال اسم «الموسوعة الإسلامية الكبرى» باسم «مكتبة القيّوم». حُذفت ملفات التصميم المرئي القديم غير المستخدمة، وأعيد تنظيم CSS في ملف واحد حتى لا تختلط قوالب الواجهات.

## رفع الواجهة
1. فك ضغط الحزمة.
2. افتح مجلد `Al-Qayyum-Islamic-Library`.
3. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages، بحيث يكون `index.html` في الجذر.
4. فعّل GitHub Pages من الفرع والمجلد الصحيحين.

## الملفات المهمة
- `index.html`, `styles.css`, `app.js`: الواجهة الموحدة والتنقل والأقسام.
- `assets/`: أغلفة الكتب والزخارف المقتبسة من صورة الواجهة المعتمدة.
- `docs/approved-interface-reference.png`: الصورة المرجعية الأصلية للتصميم.
- `locales/languages.json`: العربية الأصلية و50 لغة إضافية مع اتجاه الكتابة.
- `database/001_core_schema.sql` إلى `004_security_community_backups.sql`: مخططات قاعدة البيانات.
- `docs/MASTER_PLAN_AR.md`: الخطة الشاملة والقرارات.
- `docs/ROADMAP_AR.md`: مراحل التنفيذ.
- `docs/INTERFACE_REPAIR_AR.md`: سجل إصلاح دمج الواجهات.

## ملاحظة مهمة
هذه واجهة Front-end وليست منصة مكتملة الخدمات. اختيار لغة غير العربية يبدّل اسم اللغة واتجاه الصفحة فقط؛ ملفات الترجمة الكاملة غير منجزة. النماذج التجريبية لا ترسل بيانات إلى خادم. الكتب الظاهرة في الصفحة الرئيسية نماذج تصميمية وليست سجلات مكتملة في قاعدة بيانات حية. يجب مراجعة ملفات SQL وتشغيلها على PostgreSQL تجريبي قبل أي نشر إنتاجي.
