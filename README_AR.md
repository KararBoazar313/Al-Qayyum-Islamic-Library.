# مكتبة القيّوم — الواجهة والحزمة التشغيلية

تعتمد الواجهة التصميم المرجعي المعتمد في `docs/approved-interface-reference.png`، ولا تستبدل تخطيط الصفحة الرئيسية.

## محتويات الحزمة
- `index.html`, `styles.css`, `app.js`: الواجهة الموحدة والعارض المحلي PDF/EPUB.
- `locales/languages.json`: 51 لغة واتجاهاتها؛ الترجمة الآلية ليست ترجمة علمية مراجعة.
- `assets/`: الأغلفة والزخارف المعتمدة.
- `database/001..012`: مخططات PostgreSQL، وآخرها سير الحقوق والملفات والقراءة والملاحظات والاستيراد.
- `server/`: API مستقل للحسابات والفهرس والحقوق والملفات الخاصة والدفعات والبحوث.
- `tools/`: موائمات المصادر، كشف التكرار، مراجعة الحقوق، واستيراد الدفعات.
- `tests/`: اختبارات الأدوات وفحوص API الساكنة.
- `docs/`: خطط المشروع ودليل التشغيل والمراجعة وحالة التنفيذ.

## تجربة الواجهة الثابتة
ارفع ملفات الواجهة إلى GitHub Pages. قارئ الجهاز يفتح PDF محلياً، وEPUB عبر epub.js عند توفر الاتصال. العلامات والملاحظات في هذا الوضع تُحفظ محلياً في المتصفح.

## تشغيل خدمات الخادم
GitHub Pages لا يشغّل Node.js أو PostgreSQL. راجع `docs/API_AND_DEPLOYMENT_AR.md` لتشغيل الخادم وقاعدة البيانات على استضافة منفصلة. لا ترفع `.env` أو `server/storage/private` إلى مستودع عام.

## حقوق الكتب والملفات
لا توجد كتب حقيقية أو ملفات كاملة أُضيفت تلقائياً. كل سجل مصدر غير موثق يبقى قيد المراجعة. لا يُسمح بإتاحة ملف قبل الفحص التقني وقرار الحقوق البشري. راجع `docs/REVIEW_WORKFLOW_AR.md`.

## الاختبارات
```bash
python -m unittest discover -s tests -v
node --test tests/server-smoke.test.js
node --check app.js
node --check server/src/index.js
python -m py_compile tools/*.py
```

## حدود الحالة الحالية
هذه حزمة كود محلية تشمل المراحل 1–60 برمجياً. آخر تدقيق: 44 اختبار Node و9 اختبارات Python ناجحة. لم تُشغّل migrations على PostgreSQL ولم يُنشر API، كما يجب إضافة عنوان API إلى `index.html` قبل الربط؛ راجع `docs/AUDIT_REPORT_AR.md` و`docs/PHASE_STATUS_AR.md` قبل أي نشر.


### قارئ مكتبة القيّوم
أضيف قارئ PDF وEPUB داخل الموقع. يدعم ملفات الجهاز للتجربة وروابط الملفات المستضافة على نطاق القيّوم أو خادمها المضبوط. تفاصيل الإعداد والقيود في `docs/PHASE2_READER_AR.md`.
