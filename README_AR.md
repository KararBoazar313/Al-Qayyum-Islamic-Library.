# مكتبة القيّوم — الحزمة البرمجية التأسيسية المدمجة

أضيفت إلى هذه النسخة واجهة ويب عربية أولية قابلة للنشر على GitHub Pages (`index.html` و`assets/`). الواجهة تتضمن بحثاً استكشافياً في مصادر الفهرسة وتصنيفات ومدارس.\n\nهذه حزمة تأسيسية قابلة للتطوير. ليست موقعاً منشوراً، ولا قاعدة بيانات مشغّلة، ولا تحتوي على 200 ألف كتاب.

## المحتويات
- `database/001_core_schema.sql`: الحسابات والكتب والمؤلفون والطبعات والمدارس والمصادر والملفات والمراجعة.
- `database/002_platform_modules.sql`: الروايات والأسانيد والقراءة والبحوث والذاكرة العلمية والمجتمع والتوثيق والتقويم والدعم والإدارة.
- `database/003_catalog_import.sql`: مصادر الفهرسة ودفعات الاستيراد وسجلات البيانات الخام.
- `docs/`: حزمة فهرسة المستخدم، قالب CSV، التصنيفات، مخطط البيانات، ودليل الدمج.
- `tools_validate_catalog.py`: أداة تحقق CSV قبل الاستيراد.

## متطلبات قاعدة البيانات
PostgreSQL 16 أو أحدث، مع صلاحية إنشاء الامتداد `pgcrypto`.

## ترتيب التشغيل
```bash
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f database/001_core_schema.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f database/002_platform_modules.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f database/003_catalog_import.sql
```

## فحص ملف فهرس
```bash
python tools_validate_catalog.py docs/قالب_استيراد_الكتب.csv --out validation-report.json
```

## أعداد الكتب
100,000 عمل شيعي و100,000 عمل سني وبقية المدارس أهداف جمع وفهرسة. لا توجد هذه الأعداد ضمن الحزمة الحالية. تُستورد البيانات على دفعات موثقة، ولا تُختلق عناوين أو روابط أو انتماءات مذهبية.

## قبل الإنتاج
يلزم اختبار الترحيلات على PostgreSQL، وإعداد تخزين الملفات، وصلاحيات الصفوف والتحقق على الخادم، وفحص حقوق النشر، والنسخ الاحتياطي، ومراجعة الأمان.


## نشر الواجهة على GitHub Pages
1. ارفع محتويات هذا المجلد إلى جذر المستودع (بحيث يكون `index.html` في الجذر).
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`، واضغط Save.
4. انتظر اكتمال النشر وافتح رابط Pages.

ملاحظة: البحث الحالي دليل استكشاف للمصادر وليس بحثاً في قاعدة كتب؛ يلزم backend وقاعدة بيانات لعرض سجلات الكتب الفعلية وحسابات المستخدمين والميزات المتقدمة.
