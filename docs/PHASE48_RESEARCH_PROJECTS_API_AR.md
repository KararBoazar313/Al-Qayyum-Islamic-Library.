# المرحلة 48 — ربط مشاريع مركز البحوث بالحساب

## المنجز في الحزمة
- إضافة جدول مستقل للمشاريع البحثية الخاصة بكل مستخدم عبر migration 009.
- API لإنشاء المشاريع وعرضها وتحديث حالتها وحذفها.
- جميع الاستعلامات مقيدة بمعرّف الحساب المصادق عليه؛ لا يستطيع المستخدم قراءة مشاريع غيره أو تعديلها.
- ربط واجهة مركز البحوث بالـ API عند تسجيل الدخول وضبط الخادم.
- إبقاء وضع التخزين المحلي متاحاً عند عدم وجود جلسة دخول، مع توضيح مصدر البيانات.
- إضافة اختيار نوع المشروع: بحث، دراسة، تحقيق نص، مقارنة أدلة، أو خطة قراءة.

## التحقق
- `node --check app.js`
- `node --check server/src/index.js`
- `npm test --prefix server`
- `python -m pytest -q`

## المتبقي
- ربط أبواب وفصول البحث ومصادره وإصداراته ببيانات مستقلة.
- البحث الحديثي والرجالي لا يزال يحتاج قاعدة نصوص وأسانيد موثقة وواجهات استعلام متخصصة.
- تطبيق migration 009 على PostgreSQL الإنتاج بعد إعداد الخادم.
