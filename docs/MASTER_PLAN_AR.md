# الخطة الشاملة لمكتبة القيّوم

## الهوية والواجهة
- الاسم الرسمي: مكتبة القيّوم. اللغة الأصلية: العربية واتجاه RTL.
- اعتماد صورة الواجهة المرجعية التي اختارها المالك: شريط علوي كحلي ملكي، زخارف ذهبية، خلفية عاجية، قائمة جانبية، لوحة إحصاءات، بطاقات كتب، ولوحات الأخبار والبحوث والمقالات.
- يمنع تغيير توزيع الصفحة الرئيسية أو ألوانها أو هويتها إلا بموافقة المالك. يسمح بإضافة روابط وأقسام داخل نفس النظام البصري.
- تصميم متجاوب للهاتف والحاسوب، وقائمة هاتف قابلة للفتح.

## أقسام المعرفة والفهرسة
القرآن وعلومه، العقائد والكلام، أهل البيت والسيرة، الحديث والروايات، الفقه وأصوله، التاريخ الإسلامي، الرجال والتراجم والطبقات، الأخلاق والآداب، الدعاء والزيارة، اللغة والنحو والصرف والبلاغة، الأدب، المنطق والفلسفة، العلوم الطبيعية والاجتماعية، الجغرافيا والرحلات، السياسة والاجتماع، الاقتصاد والقانون، الرسائل والأبحاث، المخطوطات والفهارس، الموسوعات والمعاجم، الدراسات المقارنة، الترجمات، المصادر والمراجع، الناشرون والطبعات، الملفات والكتب الرقمية.

## نموذج الكتاب والفهرس
- فصل العمل العلمي عن الطبعة وعن النسخة الرقمية وعن الترجمة وعن المجلد.
- حقول الفهرسة: العنوان الأصلي والبديل، المؤلفون، المحققون، المدرسة/المدارس، التخصصات، اللغة، الناشر، الطبعة، السنة، المجلدات، الصفحات، المصدر، الكلمات المفتاحية، وصف المحتوى، حالة الحقوق.
- استيراد CSV وXLSX وJSON وواجهات APIs، مع حفظ مصدر الاستيراد وتاريخه.
- كشف التكرار دون دمج آلي غير قابل للتراجع. سير المراجعة: جديد، فحص، تصحيح، مراجعة علمية، معتمد، حقوق مقيدة، مرفوض.
- لا يُتاح تنزيل ملف قبل التحقق من الترخيص أو حالة الملكية العامة أو إذن الناشر.

## الموسوعة الحديثية والرجالية
- البحث بالنص والرقم والصفحة والراوي وجزء السند والباب والمصدر والمؤلف والمجلد والطبعة والموضوع والألفاظ البديلة.
- بطاقة الرواية: المتن، السند، الرواة، المصدر، الباب، الجزء، الصفحة، رقم الحديث، الطبعة، الناشر، وأحكام العلماء مع مصدر كل حكم ومنهجه.
- ملفات الرواة: الأسماء والكنى والألقاب والتواريخ والطبقة والشيوخ والتلاميذ وأقوال الرجاليين.
- مقارنة المتون والأسانيد والطرق، مع إبقاء النص الأصلي وربط كل فرق بمصدره. مخرجات الخوارزمية اقتراحات غير قطعية ولا تدمج الرواة المتشابهين تلقائياً.
- عدم توحيد أحكام المدارس الحديثية أو نسبة حكم إلى عالم بلا إحالة.

## الباحث والقراءة
- مشاريع البحوث، دفتر الملاحظات، الاقتباسات، الإحالات، سجل الإصدارات، العلامات المرجعية، تقدم القراءة، مؤقت القراءة، وخطط المطالعة.
- قارئ PDF والنصوص مع ربط الملاحظة بالطبعة والصفحة.
- اختبارات فهم وحفظ لا تُنشأ إلا من نص كتاب متاح وموثق، مع إظهار الصفحة المرجعية.
- المساعد العلمي يذكر مصادره ويُظهر عدم اليقين ويفصل النص المنقول عن الاستنتاج، ولا يخترع إحالات.

## الرقمنة والمخطوطات
- مدخلات PDF النصي والمصور، TIFF/PNG/JPG، EPUB، DOCX.
- لغات OCR الأولية: العربية والفارسية والإنجليزية والتركية والفرنسية والألمانية والروسية والأردية، مع توسعة لاحقة.
- تصحيح الميل، كشف الأعمدة والهوامش والحواشي والعناوين وأرقام الصفحات، وعرض صورة الأصل بجانب النص.
- الحالات: مستخرج آلياً، يحتاج مراجعة، تمت المراجعة. لا يُعد OCR إثباتاً لحقوق النشر.

## الإدارة والحوكمة
- مالك واحد ثابت بمعرّف 313، لا ينشأ تلقائياً في ملفات SQL ولا يقبل النقل أو الاستبدال. تهيئته لاحقاً بإجراء آمن بعد إعداد الخادم.
- المالك وحده ينشئ المديرين ويمنح الصلاحيات ويغير الأقسام ويوافق العمليات الحساسة. المدير لا يرفع صلاحياته.
- صلاحيات محددة بالنطاق والقسم والمدة، إيقاف المدير فوراً، سجل تدقيق محمي، مراجعة المالك، ونسخ احتياطية واستعادة.
- الأقسام: المكتبة والفهرسة، التحقق العلمي، التحرير والمراجعة، التقنية، المجتمع، الترجمة، التقويم، الدعم، الإعلام، الجودة والأمان. الاجتماعات نصية فقط.
- لا توجد رسائل خاصة بين الأعضاء.

## المجتمع
- مجموعات وقنوات بموافقة المالك وإشراف وتقارير وحظر/طرد وتظلمات.
- مستويات الأعضاء 1–10 ونظام نقاط وأوسمة، مع مكافحة التلاعب ومراجعة بشرية. المالك يعتمد الترقيات والأوسمة يدوياً.

## التقويم والإشعارات
- التقويم الهجري أساس العرض مع الميلادي للمقارنة. توثيق مصدر كل مناسبة وإظهار اختلافات البلدان والمراجع عند وجودها.
- إشعارات الموقع والمتصفح والهاتف بعد إعداد الخادم وموافقة المستخدم.

## اللغات
- العربية هي لغة الموقع الأصلية، والقائمة تضم 50 لغة إضافية. لكل لغة رمز واتجاه كتابة. تفعيل القائمة لا يعني اكتمال الترجمة؛ يلزم تحرير ومراجعة ملفات ترجمة مستقلة.

## التقنية المقترحة
- واجهة React + TypeScript عند الانتقال إلى تطبيق كامل؛ هذه الحزمة الحالية واجهة HTML/CSS/JavaScript ثابتة قابلة للنشر على GitHub Pages.
- خادم Python/FastAPI، قاعدة PostgreSQL، بحث قابل للاستبدال، تخزين ملفات S3-compatible، اختبارات Pytest وPlaywright.
- بنية Modular Monolith أولاً، ثم فصل الخدمات عند الحاجة. بيئات development/staging/production، migrations، نسخ احتياطية، rollback، وسرّيات خارج المستودع.

## الحالة الحالية بصدق
هذه الحزمة تضم واجهة أولية موسعة، وسجل لغات، وأربعة ملفات SQL، وخطة ووثائق. لا يوجد خادم متصل أو حسابات فعلية أو محرك بحث حي أو OCR عامل أو ذكاء اصطناعي متصل. لا توجد قاعدة PostgreSQL مشغّلة هنا، ولذلك لم يُدّعَ اختبار SQL على خادم حقيقي. الأرقام في واجهة الإحصاءات غير حقيقية وتظل شرطات/قريباً.
