# المخطط الشامل لمكتبة القيّوم

> هذا المستند يجمع المتطلبات والقرارات المعتمدة والأعمال المستقبلية. وجود ميزة في المخطط لا يعني أنها مبرمجة أو منشورة.

## 1. الرؤية والهوية
- مكتبة علمية رقمية متعددة المدارس الإسلامية واللغات والتخصصات.
- الاسم المعتمد: **مكتبة القيّوم — Al-Qayyum Islamic Library**.
- الهوية البصرية: كحلي ملكي، ذهبي معدني هادئ، عاجي، زخارف إسلامية؛ واجهة متجاوبة تبدأ بالهاتف.
- احترام المرجع البصري الذي اعتمده المالك، مع صفحات داخلية متناسقة.
- دعم RTL وLTR وإمكانية الوصول وتقليل الحركة والتباين وحجم الخط.

## 2. اللغات والتوطين
- اللغة الأصلية للواجهة: العربية (`ar`) والاتجاه الافتراضي RTL.
- قائمة اللغات الأولية الكاملة ورموزها واتجاهاتها في `locales/languages.json` (51 لغة بما فيها العربية).
- اختيار اللغة يبدّل اللغة والاتجاه في الواجهة التجريبية؛ لا يعني أن جميع النصوص مترجمة حالياً.
- خطة الترجمة: ملفات ترجمة منفصلة لكل لغة، مفاتيح ثابتة، مراجعة بشرية، حالات مسودة/مراجعة/معتمدة، وتاريخ تحديث.
- لا تترجم أسماء الكتب أو النصوص الأصلية تلقائياً داخل سجلها؛ تحفظ الترجمات كحقول مرتبطة بالأصل.
- دعم تعدد أنظمة الكتابة والخطوط، وأسماء اللغات الأصلية، واللهجات/الخطوط البديلة عند الحاجة.

## 3. المدارس والتصنيف العلمي
- التراث الشيعي الإمامي الاثنا عشري، والسني بمذاهبه ومدارسه، والإباضي، والزيدي، والإسماعيلي، وسائر المدارس والتقاليد الفكرية.
- عدم دمج المدارس أو نسبة كتاب/رواية/رأي إلى مدرسة بلا دليل.
- تصنيف هرمي للتخصصات والموضوعات وأنواع المصنفات والمواد.
- التخصصات تشمل: العقائد والكلام، القرآن وعلومه، الحديث والرجال، الفقه وأصوله، التاريخ والسيرة، التراجم والطبقات، الأخلاق، الدعاء والزيارة، الفلسفة والمنطق، اللغة والأدب، العلوم الطبيعية، الجغرافيا والرحلات، السياسة والاجتماع، المخطوطات، الرسائل والأبحاث، الموسوعات والمعاجم.

## 4. فهرس الكتب والمصادر
- فصل الكيان الفكري (Work) عن الطبعة (Edition) والنسخة الرقمية (Digital Copy) والترجمة والمجلد.
- بيانات الفهرسة: العنوان الأصلي والمقنن، المؤلفون والمحققون والمترجمون، المدرسة، التخصص، الناشر، الطبعة، السنة، اللغة، المجلدات والصفحات، ISBN إن وجد، الكلمات المفتاحية، المصدر، الحقوق، وحالة التحقق.
- مصادر الاستيراد وسجل الدفعات وملفات CSV/JSON وواجهات API مع حفظ المصدر وتاريخ الاستيراد وبصمة الملف.
- كشف التكرار ومراجعة السجلات قبل اعتمادها.
- سير العمل: وارد → تحقق تقني → تصحيح → مراجعة علمية → معتمد / مقيد الحقوق / مرفوض.
- الهدف البعيد: 100,000 كتاب شيعي و100,000 كتاب سني ومجموعات إضافية لبقية المدارس؛ هذه أهداف وليست أعداداً متاحة حالياً.

## 5. البحث والاكتشاف
- بحث بعنوان الكتاب أو المؤلف أو جزء من النص أو رقم الصفحة أو المجلد أو المصدر أو اللغة أو المدرسة أو الموضوع.
- أوضاع مستقبلية: مطابق، جزئي، لغوي، دلالي، ذو صلة، ومقارنة الطبعات.
- فلاتر متراكبة قابلة للحفظ، واقتراحات إكمال، وسجل بحث المستخدم.
- محرك البحث قابل للاستبدال ولا يكون مصدر الحقيقة؛ PostgreSQL هو سجل البيانات الأساسي.

## 6. قارئ الكتب ومكتبة الباحث
- قارئ PDF والنصوص وEPUB، فهرس صفحات، حفظ موضع القراءة، علامات، اقتباسات، ملاحظات مرتبطة بالصفحة والطبعة.
- رفوف ومجموعات شخصية، سجل قراءة، مؤقت قراءة وإحصاءات.
- دفتر المطالعة والتحقيق وتخريج النصوص وإدارة الدروس.
- اختبارات فهم مبنية على نص الكتاب (15 سؤالاً متنوعاً) واختبارات حفظ للروايات؛ لا تُنشأ أسئلة غير مستندة إلى النص.
- تصدير ملاحظات وتقارير PDF/DOCX في مرحلة لاحقة.

## 7. موسوعة الحديث والروايات
- سجل المتن، النصوص البديلة، السند، الرواة، الطرق، التخريج، المصدر، المؤلف، الكتاب، الباب، الجزء، الصفحة، رقم الحديث، الطبعة والناشر.
- ملفات للرواة: الأسماء والكنى والألقاب، الطبقة والتواريخ، الشيوخ والتلاميذ، أقوال الرجاليين ومصادرها.
- ربط الرواية بالآيات والفقه والكلام والتاريخ واللغة والشروح والاعتراضات.
- كل علاقة علمية تحمل مصدرها وموضعها ونوعها وحالة التحقق.
- أحكام الحديث تُنسب إلى العالم ومصدره ومنهجه؛ لا يوجد حكم آلي نهائي ولا تعميم بين المدارس.
- مقارنة المتون والأسانيد تعرض الفروق والزيادات والنواقص والتفرعات والرواة المشتركين؛ اقتراحات الآلة غير قطعية ولا تدمج الرواة المتشابهين دون دليل.

## 8. المساعد العلمي والذكاء الاصطناعي
- إجابات مفصلة بالمصادر والأدلة مع إظهار المدرسة والمنهج.
- التمييز بين النص المنقول والتحليل والاستنتاج والاحتمال.
- عدم اختلاق كتاب أو صفحة أو سند؛ إظهار مواضع عدم اليقين.
- نطاق المصادر يحدده المستخدم/المالك (المكتبة فقط أو المكتبة ومصادر خارجية).
- مخرجات الذكاء الاصطناعي اقتراحات تحتاج مراجعة بشرية قبل اعتمادها علمياً.

## 9. رقمنة الكتب والمخطوطات
- استقبال PDF نصي/مصوّر، صور TIFF/PNG/JPG، EPUB وDOCX.
- OCR وHTR للكتب والمخطوطات، تصحيح الميل، اكتشاف الأعمدة والهوامش والحواشي والعناوين وأرقام الصفحات.
- عرض الصورة الأصلية بجانب النص المستخرج وربط النص بالصفحة والطبعة.
- حالات: مستخرج آلياً، يحتاج مراجعة، تمت المراجعة.
- لغات الرقمنة قابلة للتوسع؛ لا يُفترض أن OCR لكل لغة متاح بالدقة نفسها.
- حقوق النشر تُراجع قبل العرض أو التنزيل؛ الرقمنة لا تمنح حق إعادة النشر.

## 10. الحسابات والأمان والصلاحيات
- مالك واحد ثابت بمعرّف عام 313؛ لا ينشأ تلقائياً داخل ملفات SQL، بل بإجراء تهيئة آمن بعد إعداد الخادم.
- المالك وحده ينشئ المديرين ويمنح الصلاحيات ويغيّر نطاقاتهم ويوافق على الإجراءات الحساسة.
- المدير لا يرفع صلاحياته ذاتياً؛ التفويض محدود ومحدد بالقسم والمدة والنطاق.
- تجميد المدير وإلغاء الجلسات والصلاحيات فوراً عند الحاجة.
- MFA إلزامي للمالك، اختياري/قابل للفرض على بقية الحسابات.
- تجزئة كلمات المرور، جلسات آمنة، حماية CSRF/CORS، محددات معدل، سجلات أمنية، ومراجعة أحداث الدخول.
- سجل تدقيق append-only بصلاحيات خادم منفصلة ونسخ احتياطي؛ لا يُعد مجرد جدول SQL ضماناً ضد العبث.
- لا كلمات مرور أو مفاتيح API أو أسرار في HTML/JavaScript أو GitHub.

## 11. الإدارة والموظفون
- مركز تحكم المالك ببطاقات رئيسية وقائمة جانبية، كحلي ملكي وذهبي وعاجي.
- أقسام أولية: المكتبة والفهرسة، التحقق العلمي، التحرير والمراجعة، التقنية، المجتمع، الترجمة، التقويم، الدعم، الإعلام، الجودة والأمان.
- مستويات موظفين 1–10 لا تمنح صلاحيات تلقائياً.
- ملفات موظفين، إسناد مهام ومشاريع، تقارير وتقييمات وتظلمات، ومراجعة المالك.
- الاجتماعات نصية فقط.
- كل طلب يظهر للمالك حتى لو أُسند إلى موظف؛ الأعمال الحساسة تتطلب موافقته.

## 12. المشاريع والمهام والاجتماعات
- قوالب جاهزة مع إمكانية إنشاء مشروع من الصفر.
- مهام ومراحل ومواعيد واعتماد ومرفقات وتعليقات داخل المشروع.
- صلاحيات المشروع مستقلة عن رتبة الموظف، مع سجل تغييرات.
- اجتماعات نصية بمحاضر وقرارات ومهام متابعة؛ لا اجتماعات صوتية/مرئية ضمن النطاق المعتمد حالياً.

## 13. المجتمع والمجموعات والقنوات
- مجموعات وقنوات علمية تُنشأ بعد موافقة المالك، مع مشرفين ونظام بلاغات وقرارات واستئناف.
- لا توجد رسائل خاصة بين الأعضاء؛ التفاعل العام عبر المجموعات والقنوات والدعم.
- مستويات أعضاء 1–10 وعتبات نقاط: 1,000؛ 2,000؛ 4,000؛ 8,000؛ 16,000؛ 32,000؛ 64,000؛ 128,000؛ 256,000؛ 512,000.
- توزيع النقاط المقترح: 40% محتوى موثق، 30% فعاليات، 20% تفاعل حقيقي، 10% نمو أعضاء حقيقي.
- مكافحة التلاعب ومراجعة قبل العقوبات؛ المالك يوافق يدوياً على الترقيات والأوسمة.
- الأوسمة: البداية، النشاط، التفاعل، التميز، النخبة، الريادة، الاحتراف، الإبداع، السيادة، القيّوم.

## 14. التقويم والمناسبات والإشعارات
- التقويم الهجري أساس مع عرض الميلادي والمنطقة الزمنية.
- اختلاف ثبوت الأشهر والمناسبات يعرض بوضوح مع اسم الجهة/المنهج والمصدر، ولا يُخفى الاختلاف.
- اعتماد المناسبات بعد مراجعة علمية، وتوثيق تواريخها ومصادرها.
- مركز إشعارات وتفضيلات لكل نوع، quiet hours، وإشعارات المتصفح والهاتف بعد موافقة المستخدم.

## 15. الحقوق والخصوصية
- لا يُتاح ملف للتنزيل إلا بعد التحقق من الترخيص أو الإذن.
- تخزين مصدر السجل والطبعة وبيانات الحقوق وتاريخ المراجعة.
- سياسة خصوصية وشروط استخدام وطلبات حذف/تصدير بيانات وفق القانون المنطبق.
- تقليل البيانات الشخصية وعدم إظهار بيانات الحساب الحساسة في السجلات العامة.

## 16. التقنية المقترحة
- الواجهة: React + TypeScript عند الانتقال من النموذج الثابت إلى التطبيق الكامل؛ الواجهة الحالية HTML/CSS/JS تجريبية.
- الخادم: Python + FastAPI، بنية Modular Monolith أولاً.
- قاعدة البيانات: PostgreSQL؛ محرك البحث OpenSearch أو بديل قابل للاستبدال.
- تخزين الملفات: S3-compatible خاص ومشفّر.
- الرقمنة: eScriptorium/Kraken بعد اختبار ملاءمة اللغة والمخطوط.
- الاختبارات: Pytest وPlaywright، وفحوص أمنية وأداء.
- PWA أولاً ثم تطبيق هاتف/سطح مكتب عبر API مشترك عند الحاجة.
- بيئات development/staging/production منفصلة، migrations مرقمة، backups وrollback وchangelog.

## 17. البنية المقترحة للمستودع عند التوسع

```text
packages/shared-ui | localization | permissions | shared-types

storage/books | storage/images | storage/manuscripts
tests | docs | infrastructure
```

## 18. مراحل التنفيذ
1. اعتماد الهوية والواجهة وتجربة الهاتف.
2. مراجعة قاعدة البيانات وتشغيلها على PostgreSQL تجريبي.
3. API والمصادقة والصلاحيات وسجل التدقيق.
4. فهرس الكتب والاستيراد والبحث والحقوق.
5. القارئ ومكتبة الباحث.
6. الموسوعة الحديثية والروابط العلمية ومقارنة الطرق والمتون.
7. الإدارة والموظفون والمشاريع والمجتمع.
8. اللغات والترجمة البشرية والتقويم والإشعارات.
9. الرقمنة وOCR/HTR والمساعد العلمي.
10. اختبارات أمن وأداء ونسخ واستعادة وإطلاق تدريجي.

## 19. ما هو موجود فعلياً في هذه الحزمة
- واجهة أمامية ثابتة متعددة الصفحات قابلة للمعاينة، مع قائمة لغات 51 لغة واتجاهاتها.
- أربعة ملفات SQL مرتبة كمخطط أولي.
- ملفات توثيق وخارطة طريق وقوالب استيراد وأداة تحقق كتالوج.
- لا يوجد خادم API منشور أو قاعدة بيانات حية أو تسجيل دخول حقيقي أو بحث دلالي أو OCR عامل أو ترجمة كاملة.
- لا تعتبر أعداد الكتب المستهدفة أعداداً مفهرسة؛ بيانات الدفعة التجريبية منفصلة.
