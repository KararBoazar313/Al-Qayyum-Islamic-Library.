# سير مراجعة الفهرس والحقوق

1. **استقبال البيانات:** حفظ الملف الأصلي وبصمة SHA-256 واسم المصدر ومعرّف السجل الأصلي.
2. **تطبيع:** تحويل الحقول إلى قالب القيّوم دون اختلاق ترجمة أو مؤلف أو مذهب أو ترخيص.
3. **التحقق:** إلزام عنوان أصلي أو عربي، ومؤلف إن كان معروفاً، واللغة، والمصدر، ومعرّف المصدر، وحالة التحقق.
4. **كشف التشابه:** اقتراح مجموعات مرشحة. الطبعات المختلفة لا تدمج، وتشابه أسماء المؤلفين لا يثبت اتحاد الشخص.
5. **المراجعة العلمية:** فحص نسبة العمل والمؤلف والطبعة والمحقق والمعلومات الببليوغرافية وإرفاق الأدلة.
6. **مراجعة الحقوق:** حفظ اسم الرخصة ورابطها ونصها الأصلي ومصدر الدليل وحالة الوصول واسم المراجع وتاريخ القرار والانتهاء.
7. **الملفات:** فحص تقني خارجي، حجر خاص، ثم قرار حقوق. المجهول أو المتنازع عليه لا يفتح للقراءة أو التنزيل.
8. **الاستيراد:** staging بمعاملة واحدة؛ تكرار المصدر/المعرّف لا يُدخل ثانية؛ أي فشل يعيد المعاملة.
9. **النشر:** اعتماد بشري صريح للبيانات، وقرار مستقل لإتاحة النص. الموافقة على بيانات الكتاب لا تعني حق نشر الملف.

## معاني القرارات
- `approve_metadata_only`: السماح بعرض البيانات الوصفية فقط.
- `approve_reading`: السماح بالقراءة وفق نطاق الإذن؛ لا يعني حق التنزيل أو إعادة التوزيع.
- `approve_distribution`: السماح بالتوزيع فقط عند وجود دليل واضح ورخصة تسمح به.
- `hold`: إبقاء السجل/الملف محجوباً لحين اكتمال الأدلة.
- `reject`: رفض الإتاحة.
