# نظام المجموعات والقنوات العلمية

## دورة إنشاء المساحة
1. يرسل المستخدم المسجل طلب إنشاء مجموعة أو قناة.
2. تُنشأ المساحة بحالة `pending_owner_review` ولا تظهر في الدليل العام.
3. يراجع المالك الطلب ويعتمده أو يرفضه أو يوقفه.
4. يصبح منشئ المساحة مديراً لها بعد اعتمادها.

## العضويات
- الانضمام إلى المساحة العامة يُفعّل العضوية مباشرة.
- الانضمام إلى المساحة الخاصة يبقى `pending` حتى يراجعه مدير المساحة.
- لا يمكن للمستخدم تجاوز الحظر أو الكتم بإعادة طلب الانضمام.
- يستطيع العضو مغادرة المساحة.

## المنشورات
- المنشورات الجديدة تبدأ بحالة `pending` ولا تظهر في التغذية العامة.
- أعضاء المجموعة النشطون يستطيعون إرسال منشورات للمراجعة.
- القناة تسمح بالنشر للمدير أو المشرف فقط.
- مدير أو مشرف المساحة يستطيع مراجعة المنشورات التابعة لمساحته؛ والمالك يستطيع مراجعة الجميع.
- قرارات المراجعة تحفظ في سجل التدقيق.

## الصلاحيات
- مراجعة طلب إنشاء المساحة للمالك وحده.
- منح دور مدير أو مشرف داخل المساحة للمالك وحده.
- يستطيع مدير/مشرف المساحة إدارة حالات العضوية ومراجعة منشورات مساحته فقط.
- جميع عمليات القراءة والكتابة تتحقق من العضوية والحالة على الخادم.

## API
- `GET /api/community/spaces`
- `POST /api/community/spaces`
- `POST /api/community/spaces/:id/join`
- `DELETE /api/community/spaces/:id/membership`
- `GET /api/community/spaces/:id/posts`
- `POST /api/community/spaces/:id/posts`
- `GET /api/admin/community/spaces` (المالك فقط)
- `PATCH /api/admin/community/spaces/:id` (المالك فقط)
- `GET /api/admin/community/spaces/:id/members`
- `PATCH /api/admin/community/spaces/:id/members/:userId`
- `GET /api/admin/community/spaces/:id/posts/pending`
- `PATCH /api/admin/community/posts/:id/moderation`

## ملاحظات التشغيل
يعتمد هذا التحديث على الجداول `community_spaces` و`community_members` و`community_posts` الموجودة في الترحيل 002. يضيف الترحيل 008 فهارس لتحسين دليل المساحات وقوائم المراجعة. يجب تشغيل الترحيلات على PostgreSQL قبل استخدام هذه الوظائف.

## واجهات إدارة المجتمع (المرحلة 47)
- صفحة المساحة تعرض أدوات إدارة الأعضاء ومراجعة المنشورات للمدير/المشرف المخوّل أو المالك.
- يستطيع المدير/المشرف تغيير حالة العضوية ضمن مساحته، بينما منح دور مدير أو مشرف يبقى للمالك حصراً.
- قرارات المنشورات: اعتماد، إبقاء مخفي، أو إزالة؛ مع إلزام تدوين سبب القرار.
- الواجهة تستدعي نقاط API المحمية، ولا تعتمد على إخفاء الأزرار وحده لمنع الوصول.
