# مكتبة القيّوم — إنجاز المراحل 51–55

## المرحلة 51: نسخ المخطوطات وفروق النص
- تسجيل النسخ بحسب الخزانة ورقم الحفظ وتاريخ النسخة.
- تسجيل القراءات المختلفة وربطها بموضعها في البحث.
- كل سجل خاص بصاحب المشروع ولا ينشر تلقائياً.

## المرحلة 52: مجموعات الحديث والمتون
- إنشاء مجموعات حديث بحثية خاصة بالمستخدم وربطها بمشروعه.
- حفظ المتن ومصدره والجزء والصفحة والباب وملاحظة الباحث.
- الحكم الافتراضي «غير محكوم عليه» ولا يصدر حكم آلي.

## المرحلة 53: الرواة والأسانيد
- سجل أسماء الرواة والكنى والنسب والتراجم ومصدر التقييم.
- تمثيل السند كسلسلة مرتبة مع ألفاظ الأداء.
- لا تُعرض حالة الراوي باعتبارها توثيقاً نهائياً قبل المراجعة.

## المرحلة 54: واجهات العمل والمراجعة
- إضافة نماذج تسجيل المخطوطات ومجموعات الحديث ضمن مساحة البحث.
- إضافة سجل مراجعة علمية معلل لكل قرار.
- تبقى السجلات خاصة بصاحبها.

## المرحلة 55: جودة البيانات والاختبار
- فهارس للاستعلامات الشائعة وسجلات المراجعة.
- ترحيلات قاعدة البيانات 012–016.
- لا يعني نجاح الاختبارات أن قاعدة الإنتاج قد رُحّلت أو أن الخادم نُشر؛ يلزم تشغيل الترحيلات على قاعدة فعلية قبل الاستخدام.

## الترحيلات
تشغّل آلية `npm run migrate` الترحيلات المرقمة بالترتيب. لا تُدخل هذه الإضافة أحاديث أو أسماء رواة من عندها؛ إنها توفر البنية لحفظ البيانات مع توثيقها ومراجعتها.
