# المرحلة الثانية — قارئ مكتبة القيّوم

## المنجز
- قارئ PDF داخل صفحة مكتبة القيّوم باستخدام PDF.js مع عرض صفحة مرسومة داخل واجهة المكتبة.
- قارئ EPUB داخل الصفحة باستخدام epub.js مع التنقل السابق/التالي.
- تكبير وتصغير PDF، والتنقل بين الصفحات، وإدخال رقم الصفحة.
- قبول ملف محلي للتجربة دون رفعه تلقائياً.
- قبول رابط نسخة مستضافة على نفس نطاق الموقع أو على نطاق API المضبوط فقط؛ يمنع فتح روابط مواقع خارجية في القارئ.
- إبقاء واجهة القارئ وهوية القيّوم حول محتوى الكتاب.

## متطلبات تشغيل النسخ المنشورة
- ملفات الكتب التي يراد عرضها للجمهور يجب أن تكون مخزنة في مساحة القيّوم أو خادمها بعد قرار حقوق صالح.
- يجب ضبط CORS عند استخدام نطاق API منفصل، والسماح لواجهة القيّوم بالوصول إلى ملفاتها.
- محركات PDF.js وEPUB.js تُحمّل من CDN؛ يلزم اتصال إنترنت أو استضافتها محلياً قبل النشر النهائي.
- لا توجد كتب حقيقية أُضيفت في هذه المرحلة، ولا يُعد إدخال رابط ملف بديلاً عن موافقة الحقوق.
