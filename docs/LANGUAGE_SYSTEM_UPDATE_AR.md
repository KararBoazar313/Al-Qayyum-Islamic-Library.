# تقرير تحديث اللغات والواجهة

## ما تم
- الإبقاء على صفحة رئيسية واحدة وملفات التصميم المعتمدة دون إعادة تصميمها.
- اعتماد العربية كلغة أصلية (`ar`) واتجاه RTL.
- توحيد قائمة اللغات في ملف JSON وداخل محدد اللغة: 51 رمزاً فريداً.
- إضافة البحث داخل قائمة اللغات وإظهار الاسم المحلي لكل لغة.
- حفظ اختيار اللغة في المتصفح واستعادته عند الزيارة التالية.
- تحديث `lang` و`dir` على عنصر HTML، وإضافة قواعد اتجاه LTR مع الحفاظ على نظام الألوان والتخطيط.
- ربط اللغات المدعومة بخدمة ترجمة آلية خارجية لترجمة النصوص الظاهرة، مع إبقاء تنبيه واضح أن الترجمة الآلية تحتاج مراجعة علمية.

## حدود يجب معرفتها
- خدمة الترجمة الخارجية تتطلب الإنترنت وقد لا تعمل في بعض الشبكات أو المتصفحات.
- بعض اللغات النادرة في القائمة لا توفر خدمة الترجمة الآلية لها ضمن المحرك الحالي؛ يمكن اختيارها وتغيير اتجاه الصفحة، لكن يلزم إعداد ملف ترجمة بشري خاص بها حتى تصبح الواجهة مترجمة بالكامل.
- لا تتم ترجمة نصوص الكتب الأصلية أو ملفات PDF نفسها؛ هذا النظام يخص واجهة الموقع والنصوص المعروضة.
- لا تُعد الترجمة الآلية للمصطلحات الحديثية والفقهية والعقدية ترجمة معتمدة قبل المراجعة.

## فحوص محلية
- `node --check app.js`: ناجح.
- تحليل `locales/languages.json`: ناجح.
- عدد اللغات: 51، وجميع الرموز فريدة.
- تطابق ترتيب ورموز اللغات بين ملف JSON ومحدد اللغة: ناجح.
- توازن أقواس CSS: ناجح.
- لم يكتمل اختبار العرض الآلي في Chromium في بيئة البناء بسبب تعليق عملية المتصفح؛ لذلك لا ندّعي نجاح اختبار بصري شامل.
