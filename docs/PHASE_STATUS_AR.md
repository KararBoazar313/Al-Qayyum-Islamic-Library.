# حالة مراحل مكتبة القيّوم

## مكتمل برمجياً ضمن الحزمة المحلية
- قسم المجموعات والقنوات: إنشاء المساحة وموافقة المالك والعضويات والمنشورات، مع واجهات إدارة الأعضاء ومراجعة المنشورات (المرحلة 47).
- بداية قسم استكمال ربط الواجهات: مشاريع مركز البحوث أصبحت محفوظة على حساب المستخدم عبر API (المرحلة 48).

## المتبقي
- استكمال مركز البحوث: أبواب وفصول ومصادر وإصدارات ومرفقات المشروع.
- ربط البحث الحديثي والرجالي بقاعدة نصوص وأسانيد موثقة، ثم واجهات الاستعلام والمقارنة.
- استكمال ربط بقية الواجهات العلمية بوحدات API وقاعدة البيانات.
- مراجعة التقويم ومصدره، وخدمة Push، والنسخ الاحتياطي على خادم فعلي.
- تشغيل PostgreSQL وتطبيق migrations 001–009، إعداد الأسرار، نشر API، ثم اختبار الإنتاج.
- استيراد كتب فعلية بعد تدقيق البيانات وحقوق الإتاحة؛ لم تُستورد كتب جديدة بهذه الدفعة.
