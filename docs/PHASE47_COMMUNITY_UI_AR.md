# المرحلة 47 — استكمال واجهات المجموعات والقنوات

## المنجز في الحزمة
- إضافة واجهة إدارة أعضاء المساحة: عرض العضو ودوره وحالة عضويته.
- تمكين المدير/المشرف من إدارة حالات العضوية ضمن المساحة التي يديرها.
- إبقاء منح أدوار المدير والمشرف للمالك وحده، مع التحقق النهائي على الخادم.
- إضافة قائمة المنشورات المعلقة وأزرار اعتمادها أو إبقائها مخفية أو إزالتها.
- طلب سبب لكل قرار مراجعة، وتسجيل القرار في سجل التدقيق عبر API.
- إظهار أدوات الإدارة فقط للمستخدم الذي يملك دوراً مناسباً في المساحة أو حساب المالك.
- الحفاظ على التصميم العام والصفحة الرئيسية دون تغيير.

## التحقق
- `node --check app.js`
- `node --check server/src/index.js`
- `npm test --prefix server`
- `python -m pytest -q`

## الحدود
- وظائف المجموعات تعتمد على تشغيل PostgreSQL وتطبيق migrations، ونشر API وضبط عنوانه.
- لا يعني نجاح الاختبارات المحلية أن المجموعات منشورة أو أن هناك أعضاء حقيقيين في قاعدة إنتاج.
