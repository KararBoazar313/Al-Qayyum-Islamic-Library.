# دليل دمج حزمة فهرسة الكتب

## ما أُضيف إلى مشروع القيّوم
- مصادر الفهرسة السبعة كما وردت في حزمة المستخدم.
- قالب CSV وحقول البيانات والتصنيفات.
- ترحيل PostgreSQL رقم `003_catalog_import.sql` لسجل المصادر ودفعات الاستيراد والسجلات الخام.
- أداة تحقق أولي `tools_validate_catalog.py` لفحص CSV قبل إدخاله إلى قاعدة البيانات.

## ما الذي لا تحتويه الحزمة؟
لا تحتوي هذه الحزمة على 100,000 عنوان شيعي أو 100,000 عنوان سني. إنها مصادر وقالب ومخطط وقواعد استيراد. يجب جمع سجلات فعلية من المصادر، ثم التحقق منها على دفعات.

## الترتيب
1. نفّذ `database/001_core_schema.sql`.
2. نفّذ `database/002_platform_modules.sql`.
3. نفّذ `database/003_catalog_import.sql`.
4. افحص أي ملف CSV:

```bash
python tools_validate_catalog.py path/to/catalog.csv --out validation-report.json
```

5. لا تنقل أي سجل من منطقة الاستيراد إلى `works` إلا بعد مراجعة المصدر والهوية والتصنيف وحقوق الملف. استخدم `catalog_import_records` لحفظ البيانات الخام وملاحظات التحقق.

## قواعد حاكمة
- لا يُستنتج المذهب من اسم المؤلف وحده.
- لا تُحسب سجلات المخطوطات ككتب كاملة قبل فحصها.
- كل سجل يحتاج معرّفاً ثابتاً ورابط مصدر.
- العمل الفكري يختلف عن الطبعة؛ الطبعات لا تُكرر العمل.
- لا يُستضاف PDF أو نص كامل إلا إذا سمحت الحقوق بذلك.
- لا تُنشأ بيانات وهمية للوصول إلى أهداف الأعداد.
