# بوابة الإطلاق النهائي — مكتبة القيّوم

لا يُفتح الموقع للجمهور إلا بعد تحقق جميع البنود التالية:

- [ ] مراجعة المالك للواجهة النهائية وسياسات النشر.
- [ ] PostgreSQL إنتاجي مع TLS ونسخة احتياطية قابلة للاستعادة.
- [ ] تشغيل migrations 001–017 والتحقق من `qayyum.schema_migrations`.
- [ ] إنشاء حساب المالك من إجراء الخادم وتفعيل MFA.
- [ ] ضبط `JWT_SECRET` و`CORS_ORIGIN` و`PUBLIC_BASE_URL` و`PRIVATE_STORAGE_DIR` خارج Git.
- [ ] وضع API خلف reverse proxy بشهادة HTTPS وحدود طلبات مناسبة.
- [ ] ربط ماسح ملفات فعلي؛ تبقى الملفات محجورة حتى الفحص ومراجعة الحقوق.
- [ ] إدخال بيانات قانونية موثقة ومراجعتها، وعدم عرض السجلات التجريبية كأنها مصادر مكتملة.
- [ ] اختبار عزل الحسابات والأدوار ومركز المالك على قاعدة فعلية.
- [ ] اختبار PDF وEPUB على الهاتف والحاسوب واختبار استعادة النسخ الاحتياطية.
- [ ] مراجعة قانونية للخصوصية والشروط وحقوق النشر.

`compose.example.yml` نموذج تشغيل أولي فقط، وليس إعداداً إنتاجياً مكتملاً؛ يلزم reverse proxy وTLS ومراقبة ونسخ احتياطية خارجية.
