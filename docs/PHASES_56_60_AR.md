# مكتبة القيّوم — إنجاز المراحل 56–60

## 56 — واجهة مستقلة لموسوعة الحديث
- ربط البحث في المتون والمصادر والرواة بسجلات الحساب المسجل.
- إنشاء مجموعات حديثية مستقلة وإضافة المتون مع بيانات المصدر والجزء والصفحة.
- إبقاء الحكم الافتراضي «غير محكوم عليه» وعدم توليد أحكام آلية.

## 57 — دليل الرواة
- إنشاء واجهة مستقلة لإضافة التراجم والكنى والنسب والتواريخ.
- حفظ نص التقييم مع مصدره وإظهار حالة المراجعة.
- تبقى التراجم غير محققة إلى أن تتم مراجعتها؛ ولا يجري استيراد أسماء أو أحكام بلا مصادر.

## 58 — جاهزية الخادم وقاعدة البيانات
- إضافة `/healthz` لفحص حياة خدمة API و`/readyz` لفحص اتصال قاعدة البيانات.
- إضافة migration 017 لفهارس مساحة الحديث والرجال.
- ترتيب خدمة الترحيل قبل تشغيل API في نموذج Docker Compose.

## 59 — الاختبار ومراجعة الأمان
- إضافة اختبارات لملكية سجلات الحديث والبحث والواجهة المستقلة ودليل الرواة.
- التحقق من صياغة JavaScript وتشغيل اختبارات Node وPython محلياً.
- بقي اختبار PostgreSQL الفعلي ومراجعة أمنية خارجية غير منفذين لعدم وجود خادم وقاعدة بيانات إنتاج متصلين.

## 60 — حزمة التشغيل والتسليم
- إضافة Dockerfile وCompose نموذجيين للخادم وقاعدة PostgreSQL والتخزين الخاص.
- إضافة فحوص الصحة والجاهزية وتعليمات بوابة الإطلاق.
- لا يتضمن ذلك إنشاء خادم سحابي أو شهادة HTTPS أو نطاق أو مفاتيح إنتاج؛ يجب على مالك المشروع إعدادها بنفسه في مزود الاستضافة.

## نتيجة الاختبارات المحلية
- Node.js: 41/41 ناجحة.
- Python: 9/9 ناجحة.
- `node --check` لملفي `app.js` و`server/src/index.js`: ناجح.
- ZIP: فحص السلامة بعد التصدير.

## ما لا يزال خارج الإنجاز
1. إنشاء قاعدة PostgreSQL فعلية، وأخذ نسخة احتياطية، ثم تطبيق migrations 001–017 عليها.
2. إدخال بيانات حديثية ورجالية ومخطوطات موثوقة مع المصدر والطبعة والحقوق، ثم مراجعتها علمياً.
3. إعداد مزود ماسح ملفات ومزود بريد/Push عند الحاجة.
4. إعداد نطاق وHTTPS وبيئة أسرار آمنة، ثم اختبار الاستعادة والتحميل على أجهزة فعلية.
5. مراجعة سياسة الخصوصية وشروط الاستخدام والحقوق قانونياً قبل فتح الخدمة للجمهور.

**حالة الإطلاق: غير جاهز للنشر العام حتى إكمال البنود الخارجية أعلاه.**
