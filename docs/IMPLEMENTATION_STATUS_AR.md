# حالة تنفيذ مكتبة القيّوم — 17 نوفمبر 2026

## النتيجة
اكتمل تنفيذ حزمة الكود المحلية للمراحل التسع: أدوات الفهرسة والمراجعة، مخطط قاعدة البيانات، API خادمي، قارئ محلي، إدارة ملفات خاصة، الملاحظات والاقتباسات، الاستيراد المرحلي، والاختبارات. **هذا لا يعني أن خدمة الإنتاج قد نُشرت**: لا يوجد اتصال قاعدة بيانات أو خادم إنتاج ضمن بيئة العمل الحالية، ولذلك لم تُنفّذ migrations ولم تُنشأ حسابات حقيقية ولم تُستورد سجلات كتب حقيقية.

## المراحل التسع

| # | المرحلة | ما أصبح موجوداً في الحزمة |
|---|---|---|
| 1 | موائمات المصادر | `tools/adapt_catalog_source.py` لمصادر Open Library وInternet Archive وOpenITI وCSV الموحد، مع حفظ الخام وبصمة SHA-256. |
| 2 | مطابقة الأعمال والطبعات | `tools/match_catalog_editions.py` يخرج مرشحي التطابق ولا يدمج الطبعات أو المؤلفين آلياً. |
| 3 | مراجعة البيانات والحقوق | `tools/review_workflow.py` + جداول الحقوق + API لمراجعة الملف، قرار المراجع، الدليل، الرخصة، الوصول، والانتهاء. الحظر افتراضي. |
| 4 | المؤلفون والأعمال والطبعات | كيانات مستقلة وعلاقات `authors / works / work_authors / editions`، أدلة نسبة، وإنشاء مسودة بعد قبول سجل الاستيراد؛ لا دمج تلقائي للمؤلفين. |
| 5 | PDF وEPUB | رفع محدود الحجم، فحص توقيع الملف، SHA-256، تخزين خاص خارج `public`، حالة حجر وفحص، لا رابط عام تلقائي. |
| 6 | القارئ | PDF محلي عبر عارض المتصفح، EPUB عبر epub.js عند توفر الإنترنت، حفظ علامات محلية، وAPI موثق لبث الملفات التي اجتازت الفحص والحقوق. |
| 7 | الملاحظات والاقتباسات والبحوث | CRUD للملاحظات والاقتباسات والبحوث مع ملكية المستخدم وخصوصية `private` افتراضياً، وربط العمل/الطبعة والموضع. |
| 8 | الاستيراد والأداء | معاينة، dry-run، دفعات حتى 5,000 في API، معاملة SQL، idempotency، سجل تدقيق، قبول بشري، وعدم النشر التلقائي. |
| 9 | الاختبار والتسليم | اختبارات Python وNode، فحص بناء الملفات، اختبار دفعة اصطناعية 10,000 سجل، دليل تشغيل وحزمة موحدة. |

## ما لم يحدث — بوضوح
- لم تُشغّل PostgreSQL أو أي migration.
- لم تُربط الواجهة الثابتة تلقائياً بخادم API؛ ملفات GitHub Pages لا تشغّل Node أو PostgreSQL.
- لم تُضف كتب أو ملفات PDF/EPUB حقيقية، ولم يُفترض ترخيص أي عنوان.
- لم يُنفذ فحص مضاد فيروسات فعلي. يبقى الملف في `pending` حتى يمر على ماسح خارجي موثوق ثم يقرّر المراجع حالته.
- تسجيل الدخول في API يستخدم JWT وbcrypt، لكن يجب إعداد البريد/HTTPS وسياسة كلمات المرور وإدارة الأسرار قبل فتحه للعموم.

هذه متطلبات تشغيل خارجية وليست وظائف يمكن إكمالها بأمان من داخل ملفات الواجهة وحدها. لا ترفع `.env` أو مجلد `server/storage` إلى GitHub.
