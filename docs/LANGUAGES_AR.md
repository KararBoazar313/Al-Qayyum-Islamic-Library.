# دليل اللغات

- اللغة الأصلية: العربية (`ar`) والاتجاه RTL.
- القائمة والرموز والكتابة والاتجاه محفوظة في `locales/languages.json`.
- العدد: 51 لغة (العربية + 50 لغة إضافية).
- الاختيار الحالي يبدّل اسم اللغة وخصائص `lang` و`dir` للصفحة فقط؛ لا يترجم كل النصوص بعد.
- أسماء تحتاج ضبطاً: «المجربة» صُححت إلى «المجرية»؛ «الميلاوية» إلى «المالايوية»؛ «الإثيوبية» حُددت مبدئياً بالأمهرية؛ «الاسكتلندية» حُددت Scots لا Scottish Gaelic.
- «الهزارجية» مدرجة برمز ISO 639-3 `haz`، و«الأمازيغية» برمز مجموعة `ber`.
- بعض اللغات لها أكثر من خط أو معيار كتابة؛ يضاف اختيار الخط/النص البرمجي لاحقاً دون إنشاء لغة مكررة.
- قبل اعتماد ترجمة، يجب مراجعتها بشرياً وتسجيل المترجم وحالة الاعتماد.
