# المرحلة 50 — ربط مراجع البحوث بفهرس المكتبة

## المنجز برمجياً
- البحث داخل الأعمال المنشورة والطبعات المعتمدة فقط من واجهة مركز البحوث.
- عرض عنوان الكتاب والمؤلف وبيانات الطبعة المعتمدة لاختيار المرجع.
- ربط سجل المرجع البحثي بمعرّف العمل ومعرّف الطبعة في الفهرس، مع الإبقاء على خيار المصدر اليدوي.
- التحقق في الخادم من اعتماد الكتاب والطبعة قبل قبول الربط، مع بقاء كل العمليات ضمن ملكية المشروع.
- إضافة migration رقم 011 وفهارس لحقول الربط.

## API
- `GET /api/research/catalog-search?q=...`
- توسيع `POST /api/research/projects/:id/sources` لقبول `catalogWorkId` و`catalogEditionId` الاختياريين.

## الاختبار
- `node --check app.js`
- `node --check server/src/index.js`
- `npm test --prefix server`
- `python -m pytest -q`
