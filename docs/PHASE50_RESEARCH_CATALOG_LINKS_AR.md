# المرحلة 50 — ربط مراجع البحوث بفهرس المكتبة

## المنجز برمجياً
- إضافة migration `011_research_catalog_links.sql` لربط مرجع البحث بمعرّف طبعة من فهرس القيّوم.
- إضافة API محمي بتسجيل الدخول للبحث عن الطبعات المعتمدة فقط؛ لا تظهر الأعمال أو الطبعات غير المعتمدة في نتائج الاختيار.
- إضافة تحقق خادمي عند حفظ المرجع، ويرفض ربط أي طبعة غير معتمدة.
- إضافة اختيار الطبعة من واجهة مركز البحوث، مع إبقاء إدخال المراجع اليدوي متاحاً للمصادر التي لا تملك سجلاً في الفهرس.
- حفظ `edition_id` مع المرجع حتى يمكن تتبّع الطبعة المعتمدة.

## نقاط لم تُنجز بعد
- تطبيق migration 011 على PostgreSQL فعلي.
- لا توجد سجلات كتب حقيقية مستوردة في هذه الحزمة؛ لذلك قد تكون نتائج البحث فارغة حتى استيراد واعتماد بيانات الفهرس.
- البحث الحديثي والرجالي لا يزال غير متصل بواجهة API.

## التحقق
- Node.js: 35 اختباراً ناجحاً بعد إضافة ثلاثة اختبارات تعاقدية.
- Python: 9 اختبارات ناجحة.
- فحص صياغة `app.js` و`server/src/index.js` ناجح.
- لم يُنفذ اختبار PostgreSQL تكاملي لعدم توفر قاعدة بيانات في بيئة العمل.
