# تقرير فحوص الحزمة المحلية

أُجريت فحوص بنيوية محلية على الملفات قبل ضغط الحزمة:
- التحقق من وجود أربعة ملفات SQL وتسلسلها.
- التحقق من وجود BEGIN/COMMIT واحدين في كل ملف وتوازن عدد الأقواس.
- إصلاح قيمة `nisba` التي كانت تحتوي مسافة بادئة.
- حذف إنشاء جداول الرسائل الخاصة من ملف الوحدات، مع إبقاء قرار عدم وجود الرسائل الخاصة.
- التحقق من سجل اللغات: 51 لغة بما فيها العربية.
- التحقق من ملفات JSON عبر محلل JSON القياسي.

**حدود الاختبار:** لم يتوفر خادم PostgreSQL في بيئة إنشاء الحزمة؛ لذلك لم يُنفّذ parser أو migration integration test على PostgreSQL. يجب تنفيذ تعليمات `database/README_DATABASE_AR.md` على قاعدة اختبار قبل الإنتاج. الفحوص البنيوية لا تثبت خلو SQL من كل أخطاء التشغيل.
